[사진관리.exe 자동빌드]
1. GitHub에서 새 Repository를 만듭니다.
2. 이 폴더의 파일과 .github 폴더를 모두 업로드합니다.
3. Actions -> Build Windows EXE -> Run workflow.
4. 작업 완료 후 Artifacts -> 사진관리-Windows-EXE를 다운로드합니다.
5. 압축을 풀고 사진관리.exe를 더블클릭합니다.

기능:
- 촬영일 기준 YYYY\MM 정리
- EXIF 날짜 우선
- 사진/동영상 지원
- SHA-256 완전 동일 중복 검사
- 원본 삭제/이동 없음
- CSV 결과 보고서
- 복사 후 파일 크기 검증
- 중복파일 별도 복사 옵션
